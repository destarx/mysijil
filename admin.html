Simpan perubahan

Laman ini dihoskan di GitHub Pages. Untuk mengemas kini laman carian, data disimpan terus ke repo menggunakan token GitHub anda.

Cara dapatkan token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pilih repo ini.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Salin token dan tampal di atas.

Tukar kata laluan admin

Kata laluan baharu berkuat kuasa selepas anda tekan Simpan. Simpan kata laluan ini di tempat selamat: ia tidak boleh dipulihkan.
